# Flight Tracker

A modern, responsive web application built with Next.js to track flight details in real-time. Enter a flight number to view departure and arrival times, origin, destination, and airline information. Includes a feature to add flight details directly to Google Calendar.

## Features

- **Real-time Flight Tracking**: Search by flight number to get up-to-date information.
- **Detailed Flight Info**: View airline, origin, destination, and timing details.
- **Google Calendar Integration**: One-click add to calendar for easy scheduling.
- **Responsive Design**: Beautiful, mobile-friendly interface built with Tailwind CSS.
- **Modern Tech Stack**: Powered by Next.js 16 and React 19.

## Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Font**: Geist

## Getting Started

Follow these steps to get the project running on your local machine.

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed on your system.

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd flight-tracker
   ```

2. Install dependencies:
   ```bash
   npm install
   # or
   yarn install
   # or
   pnpm install
   # or
   bun install
   ```

### Running the App

Start the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Usage

1. Enter a valid flight number in the search bar.
2. Click the search button.
3. View the flight details card.
4. Click on the flight card to add the event to your Google Calendar.
